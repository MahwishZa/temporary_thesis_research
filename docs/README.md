`corpus/qc/` holds reports generated by QC runs on the author's machine. They
quote absolute Windows paths and dated counts because they are the record of
what was executed — they are evidence, not live references, and are left exactly
as written.

The reproduction's own specification — every assumption, and every place the
paper and the authors' released code disagree — is
[`../rag2/docs/rag2_reproduction.md`](../rag2/docs/rag2_reproduction.md), kept
with the reproduction it describes.
