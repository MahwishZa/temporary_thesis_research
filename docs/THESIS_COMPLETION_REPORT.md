## 1. The one thing to fix next

**The thesis built its secondary contribution and never built its primary one.**

The proposal is unambiguous about which is which. C1 is the Filter Recency-Bias
Probe — "the first controlled measurement of admission asymmetry with respect to
evidence age". C2 is SCAF, the corrective policy. And the proposal's own timeline
puts the probe at Phase 4 and SCAF at Phase 5, with a reason stated in the text:

> "[DES] Phase 4 precedes Phase 5 deliberately. If the primary claim fails, that
> must be discovered in month five, when a pivot is inexpensive, rather than in
> month nine."

The repository ran Phase 5 first, thoroughly and carefully, and left
`experiments/recency_bias/` containing one README saying "Not started". The
repository's own `experiments/README.md` had even written the warning down:

> "**Status: not started, and deliberately so.** Do not add [SCAF] until the
> baseline is measured: a correction has nothing to correct until the bias it
> targets has been shown to exist."

That is the sidetrack, named precisely. It is also cheap to correct — see §7.

## 4. Issues found and fixed

**4.1 ρ dropped from the admission score — fixed.**
`architecture/scaf/policy.py` computed `rho = 0.0` and labelled it
*corroboration*. The proposal's notation table defines ρ(s) as the
rank-normalised reranker score, and §4.5 explains the rank normalisation ("so
that A(s) is comparable across queries and a global admission threshold is well
defined"). Two different quantities had been conflated, and the effect was to
delete a term from A(s).

*Correction:* ρ is now computed from the frozen reranker rank and recorded on
every decision. Its weight still defaults to 0.0, so **no existing admission
decision changed** — the proposal marks weight selection `[OPEN]`, and choosing a
value here would both fabricate a parameter and violate fairness guarantee 5 (no
test-set tuning). Corroboration remains a separate, still-unimplemented concept
with its own weight key. Counterfactually, ρ at w = 0.2 would move 40 of 600
decisions, so the dropped term was material.

**4.2 The FRB-PAIRS blocker was misdiagnosed — corrected.**
`README.md`, `docs/experiments/preliminary_rag2_vs_scaf.md` and the Windows
runbook all recorded that FRB-PAIRS cannot be constructed because the corpus
holds 7 pre-2020 documents, and listed "source it externally" as one option among
three awaiting a supervisor decision. Proposal §5.2 already decides: FRB-PAIRS is
derived from **MedChangeQA**, behind a *provenance firewall* the proposal adopted
as a correction to an earlier draft of itself, in which shared authorship made a
positive result "unfalsifiable by construction". The corpus was never the source.
All three documents now say so.

**4.3 A stale checkpoint-verification artifact.**
`experiments/results/.../filter/checkpoint_verification.json` reports a FAILED
check against `runs/filter-alzheimer` ("no config.json… accelerator.save_state
directory"). The scientific run used a different, valid checkpoint,
`runs/filter-alz`, whose file listing the manifest records in full. Harmless, but
it reads as a failure of the run and is not one. Left in place as history.

**4.4 Two test defects of my own, fixed.** A `_year_fraction` copy in the
ablation module diverged from the policy's day-clamping (now pinned by a test
asserting the two agree across a date grid); and a claim-discipline test banned a
substring that legitimately appears inside the *prohibition* list (rewritten to
require a negation in the same sentence, and the report's forbidden-claim bullets
rewritten to carry their own negation so none can be quoted as an assertion).

## 5. Experiments executed this pass

All offline, all exact, none requiring a GPU, an index, a generator or a network.

**Precondition, verified first.** The frozen run reproduces its own arithmetic:
A(s) rebuilds from the recorded sub-scores to 8.0 × 10⁻⁷ across all 600
candidates, all 600 admit/reject decisions reproduce, and γ regenerates from the
publication date to 5.0 × 10⁻⁷ at as-of 2026-01-01 with H = 5 y. Without this,
none of the re-scoring below would mean anything; the runner refuses if it fails.

**5.1 Ablations A4, A5, A7, A11, A12.**

| ID | Configuration | Admitted | Decisions changed |
| --- | --- | ---: | ---: |
| — | as run | 575/600 | — |
| A4 | no filter | 600/600 | 25 |
| A5 | currency disabled (renormalised) | 423/600 | 152 |
| A7 | support excluded (renormalised) | 600/600 | 25 |
| A12a | authority removed (renormalised) | 575/600 | 4 |
| A12b | **authority ordering fully inverted** | 584/600 | **15** |

A5 and A7 are reported both zeroed and renormalised, because zeroing a weight
shrinks A(s) and silently makes a fixed threshold stricter — an artifact that
would otherwise masquerade as the effect of removing the term.

**5.2 Variance decomposition.** Share of Var(A(s)): support **83.5%**, currency
14.7%, authority 1.8%, ρ 0.0%. The implemented SCAF is, by variance, a
lexical-overlap filter. Currency cannot contribute more than it does: over a
2021–2026 corpus at a five-year half-life, γ never falls below 0.536.

**5.3 Sensitivity (A11).** Admission moves from 99.7% (θ = 0.30) to 28.2%
(θ = 0.70). Neither θ = 0.45 nor H = 5 y was fitted on validation data, so
575/600 is a property of an unfitted threshold as much as of the policy.

**5.4 Clustered statistics.** Resampling unit is the **question**, never the
passage: 20 candidates share each question, so the effective sample size is far
closer to 30 than to 600.

## 6. Findings

**6.1 Admission.** RAG² 4/600 (0.0067), SCAF 575/600 (0.9583); difference
**+0.9517**, question-clustered 95% CI [+0.9283, +0.9733], Cohen's *h* = 2.567.
Exact McNemar p ≈ 2.6 × 10⁻¹⁷² is reported only beside the clustered interval and
labelled anti-conservative. **RAG²'s admitted set is a strict subset of SCAF's**
(`rag2_only = 0`): the two policies are not trading off differently, one is
simply far more permissive.

RAG² answered 26 of 30 questions with zero admitted passages. That is closed-book
generation, not abstention, and it is a *filter over-rejection* finding in the
proposal's own error taxonomy.

**6.2 Evidence quality — the central result.** Against 120 independent human
usefulness labels, with Holm–Bonferroni across five comparisons:

| Signal | ρ | 95% CI (clustered) | Survives Holm |
| --- | ---: | --- | :---: |
| `rho_rerank` | **+0.2175** | [+0.0850, +0.3382] | **YES** |
| `sigma_support` | +0.1640 | [−0.0239, +0.3238] | no |
| `scaf_score` | +0.1237 | [−0.0418, +0.2759] | no |
| `gamma_currency` | −0.0519 | [−0.2690, +0.1721] | no |
| `rag2_score` | +0.0170 | [−0.1388, +0.1661] | no |

**Neither admission policy's score is distinguishable from noise as a predictor
of human-judged evidence usefulness.** The only signal that survives correction
is the frozen MedCPT reranker's rank — the term SCAF's implementation had
dropped, and the one neither arm consults at admission.

Also: all 14 passages the annotator judged *not relevant* were admitted by SCAF.

**6.3 Human evaluation.** 120 passages, one annotator, labels 0/1/2 distributed
14/46/60, no machine suggestion generated or shown (pass
`corrected-human-only-v1`, sheet SHA-256 `19d427cd…`). Two carried limitations:
29 of 30 questions represented with up to 8 passages from one question, and all
four RAG² admissions forced into the sample, so it is not a simple random sample
of the 600. The suggestion-anchored pilot (ρ = 0.63 on 120/120 suggestion-matched
labels) is retained as audit history and is **not** scientific human validation.

**6.4 Temporal.** Unresolved. Descriptively RAG²'s four admissions all fall in
2025–2026, pointing *away* from H1, but four admissions is not evidence of
anything.

Download MedChangeQA (Vladika et al., *Facts Fade Fast*, Findings of EMNLP 2025;

```powershell

    --dataset data\datasets\medchangeqa\medchangeqa.jsonl --dry-run
```

```powershell

    --dataset data\datasets\medchangeqa\medchangeqa.jsonl --dry-run `
    --field-map '{\"older_text\": \"abstract_old\", \"newer_date\": \"year_new\"}'
```

Then run the probe. **Fix `--equivalence-band` before looking at any output** —
§7.3 requires the band pre-registered, and choosing it afterwards turns an

```powershell
python experiments\scripts\run_frb_probe.py `
    --dataset data\datasets\medchangeqa\medchangeqa.jsonl `
    --checkpoint architecture\rag2\runs\filter-alz `
    --equivalence-band 0.05
```

Exit code 0 only if the permutation control passes; H1 is withheld otherwise, per
§4.6 control V1.

## 9. Final scientific assessment

| Claim | Supported? |
| --- | --- |
| The RAG² reproduction is faithful | **Structurally yes**, numerically unverified — no accuracy was measured |
| The SCAF implementation matches the proposal | **No** — σ is lexical, contested state absent, output policy partial, ρ was dropped |
| The RAG²-vs-SCAF comparison is fair | **For admission yes**, provably. **For answers no** — 688× context imbalance, violating fairness guarantee 2 |
| SCAF improves evidence quality | **Not supported.** Its association with independent human labels includes zero |
| Recency bias exists in the filter | **Unresolved.** The probe was never run |
| SCAF improves answer quality | **Untestable** with current artifacts — no answer-quality instrument exists |

**A negative result is a valid thesis result.** The honest finding here is that a
lexical-support-plus-currency admission score does not demonstrably select better
evidence than a confidence-derived one, and that both are outperformed at that
job by the reranker both of them inherit and ignore. That is publishable, and it
is a better outcome than a manufactured positive.

exists or does not; that matched-k differences prove superiority; that a
relevance label implies factual correctness; or that this reproduction matches
the paper's reported accuracy.
